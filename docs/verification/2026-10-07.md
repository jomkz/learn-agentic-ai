fail. Restoring the original baseline metadata resolved that validation setup issue; the full
suite then passed. Offline notebook execution required normal local async/thread support.

`.gitattributes` rule; their recorded SHA256 hashes remain unchanged.

the exact-cache diagnostic label, and unsupported ablation claims in the retrieval ADR.

installed package outside the checkout with Python isolated mode, preventing source-path
imports from hiding packaging problems.
