## Papers Reading List

Organized by the phase where each paper is most relevant.

### Phase 1 — Foundations
- "Attention Is All You Need" (Vaswani et al., 2017): https://arxiv.org/abs/1706.03762

### Phase 2 — Agents and Tools
- ReAct: "ReAct: Synergizing Reasoning and Acting in Language Models" (2022): https://arxiv.org/abs/2210.03629

### Phase 3 — RAG
- RAGAS: "RAGAS: Automated Evaluation of Retrieval Augmented Generation" (2023): https://arxiv.org/abs/2309.15217
- Sentence-BERT: https://arxiv.org/abs/1908.10084

### Phase 4 — Advanced RAG
- HyDE: "Precise Zero-Shot Dense Retrieval without Relevance Labels" (2022): https://arxiv.org/abs/2212.10496
- Self-RAG (2023): https://arxiv.org/abs/2310.11511
- CRAG: "Corrective Retrieval Augmented Generation" (2024): https://arxiv.org/abs/2401.15884
- RAG Survey: "Retrieval-Augmented Generation for LLMs: A Survey" (2023): https://arxiv.org/abs/2312.10997

### Phase 5 — Multi-Agent
- Plan-and-Solve: https://arxiv.org/abs/2305.04091
- Autonomous Agents survey: https://arxiv.org/abs/2308.11432

### Phase 6 — Safety and Context
- "Lost in the Middle: How Language Models Use Long Contexts" (2023): https://arxiv.org/abs/2307.03172
- LlamaGuard (2023): https://arxiv.org/abs/2312.06674
- Reflexion (2023): https://arxiv.org/abs/2303.11366

### Phase 8 — Fine-Tuning and Serving
- LoRA: "Low-Rank Adaptation of Large Language Models" (2021): https://arxiv.org/abs/2106.09685
- QLoRA: "Efficient Finetuning of Quantized LLMs" (2023): https://arxiv.org/abs/2305.14314
- PagedAttention / vLLM (2023): https://arxiv.org/abs/2309.06180

### Phase 9 — GraphRAG, RAFT, InstructLab
- GraphRAG: "From Local to Global: A Graph RAG Approach" (2024): https://arxiv.org/abs/2404.16130
- RAFT: "Adapting Language Model to Domain Specific RAG" (2024): https://arxiv.org/abs/2403.10131
- LAB / InstructLab: "Large-Scale Alignment for ChatBots" (2024): https://arxiv.org/abs/2403.01081
